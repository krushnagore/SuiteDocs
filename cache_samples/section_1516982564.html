Supported Record Actions

Record actions make it convenient to update records that are currently being viewed. For more information, see Overview of Record Action and Macro APIs.

Record macro APIs are part of the N/action Module. For more information, see N/action Module.

The following table lists currently supported record actions. The table is organized by record type and includes the UI button labels. For details about a specific action, click its Action ID.

Note:

For information about working with record actions in REST web services, see Executing Record Actions.
